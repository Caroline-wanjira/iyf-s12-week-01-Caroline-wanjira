# Accessibility Report
## Introduction
I conducted an accessibility report of my **index.html** webpage using **Google Chrome Lighthouse** 
The purpose of the audit was to identify accessibility and website issues and make improvements to my webpage.
### Initial Score
My starting accessibility score was 97%
### Issues Found
1. Document does not have main landmark 
Lighthouse reported that my document did not have a "<main>" landmark which i fixed by adding a "<main>" element in my webpage.
2. Image has incorrect aspect ratio.
I fixed this by adjusting my image.
3. Document does not have a meta description 
I fixed this by adding a meta description inside the "<head>" section of my `html` document .
### Final Lighthouse Score 
After making the required corrections , I ran a lighthouse audit again and my final accessibility score is 100%.
### Conclusion 
The accessibility audit helped me identify issues affecting my webpage and understand how to improve.
